# Python Time Series Analysis

A practical learning project focused on time series analysis in Python using
Pandas, NumPy, Matplotlib, SciPy, and Statsmodels.

This repository documents my progression from the fundamentals of handling
date/time data to time-series analysis, forecasting, and machine learning.

The goal is not just to memorize functions, but to understand **when, why,
and how** to use them in real-world data analysis.

---

## 🎯 Learning Goals

By completing this project, I aim to become comfortable with:

- Working with dates and times in Python
- Creating and manipulating `DatetimeIndex`
- Resampling time-series data
- Handling missing values
- Creating lag and difference features
- Calculating rolling and expanding statistics
- Visualizing time-series data
- Identifying trends and seasonality
- Decomposing time series
- Understanding and testing stationarity
- Analyzing autocorrelation and partial autocorrelation
- Building ARIMA and SARIMA models
- Applying machine learning to time-series problems
- Building an end-to-end forecasting project
